## 3. 接口数量

- Controller 类：**16 个**（`*Controller.java`）；
- 映射注解（`@GetMapping`/`@PostMapping`/`@PutMapping`/`@DeleteMapping`/类级 `@RequestMapping`）：**113 处**，其中类级 `@RequestMapping` 约 16 处，因此**实际 HTTP 端点约 95–100 个**；
- 另有 1 个 WebSocket 端点：`/ws/danmaku/{animeKey}/{episodeNum}`（`abc-danmaku-service/.../websocket/DanmakuWebSocketServer.java`）。

## 10. 工作量自评（答辩可讲的「难在哪」）

1. **不是 CRUD 堆量**：source 规则引擎、弹幕异步写链路、AI RAG 三块都需要自己设计数据结构与失败降级；
2. **跨 10 个服务的联调**：网关透传身份头、Feign 调用、Nacos 配置下发，任何一环错都表现为「另一个服务 401/500」，需要链路化排查能力；
3. **工程化落地**：20 个服务定义的编排、healthcheck 依赖顺序、离线 Maven 构建、Windows 下的脚本编码坑，这些在论文里属于「系统部署与运维」章节，是很多毕设缺失的部分；
4. **可量化**：压测脚本 + 对照实验设计 + 推荐评测协议，让「性能」和「效果」都有可复现的验证路径，而不是只凭感觉说「变快了」。
